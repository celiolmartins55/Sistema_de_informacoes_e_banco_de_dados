O presente repositório reúne os códigos em SQL elaborados durante a disciplina de “Sistemas de Informação e Bancos de Dados”, integrante da grade curricular do curso de Bacharelado em Estatística da Universidade Federal do Ceará (UFC). O autor obteve nota máxima nas atividades propostas. Este material tem como intuito estrito compor o seu portfólio técnico.

</br>

## 🌳Ambiente:
PostgreSQL via [DB Fiddle](https://www.db-fiddle.com)

</br>

## 📁Estrutura do repositório:
- `/Markdown:` Resultados das consultas exportados em formato .md.
- `/Queries:` Scripts com as resoluções em .sql.
- `/Schema:` Código para criação das tabelas e inserção dos dados no banco.
